Docker + Nginx + PHP-FPM

Security Lab

このページは、Docker を動かせない環境でも教材の資料だけを読めるようにした、静的なページです。 実際に手元で PHP・Nginx を動かして試す場合は、docker compose up -d が使える環境で http://127.0.0.1:8099/ を開いてください。

解説 → 実習 →

Docker が動かせない場合

解説（preview.html） は、 実際に環境を動かさなくても読める資料です。public/ だけを公開する理由、 Nginx と php.ini の設定の読み解き、PHP のバージョンを放置する危険性などを説明しています。

実習（lab.html） は、 手元で Docker を動かせる環境を用意できたときに、実際に設定を変更して確認する手順です。 今は手順を読むだけにして、環境が整ったら実際に試してください。

PHP のサポート期限（バージョンを放置する危険性）

この教材環境は PHP 8.4 で動かしています。古いバージョンのまま使い続けると、 セキュリティサポートが終了したあとに見つかった脆弱性が、修正されずに残ってしまいます。

⚠️ PHP 8.2 は 2026年12月31日 にセキュリティサポートが終了します

終了後は脆弱性が見つかっても修正版が出ません。8.2 を使っている環境は、早めに 8.3 以降へ移行してください。

バージョン バグ修正の終了 セキュリティ修正の終了
8.2 2024-12-31(終了) 2026-12-31
8.3 2025-12-31(終了) 2027-12-31
8.4(この環境) 2026-12-31 2028-12-31

日付は php.net の Supported Versions に基づきます。最新情報は公式サイトで確認してください。

公開しているのは public/ だけ

app/、config/、vendor/、 .env は DocumentRoot の外にあります。 public/ には機密ファイルを置かないでください。
